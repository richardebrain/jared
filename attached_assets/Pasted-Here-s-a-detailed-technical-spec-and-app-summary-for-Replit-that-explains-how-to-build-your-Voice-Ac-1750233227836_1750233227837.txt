🗣️ “Speak Into Me” — and the rest just works.

🧠 App Overview – VoiceTrack Health
Name: VoiceTrack Health
Purpose: An ultra-simple, speech-first health tracker that converts spoken input into categorized, analyzed, and visualized health data—including food intake, macros/micros, workouts, vitals, sleep, and hydration.

✅ Core Features
🎙️ 1. Voice Capture + NLP Processing
Main interface = single button:

“Speak Into Me” (large, centered button)

On tap, it:

Records voice input

Transcribes using OpenAI Whisper or Google Speech-to-Text

Processes natural language using GPT-4o or a fine-tuned model to:

Detect and classify health data (food, workouts, sleep, vitals, water, mood, etc.)

Parse quantity, units, and type

Output structured JSON or database entries per input

Example Input:

“I had a grilled chicken sandwich from Chick-fil-A, a small waffle fry, and a Coke. I also did 4 sets of bench press at 135 pounds for 8 reps each. I slept 6 hours last night but woke up twice.”

🧠 2. Health Data Categorization + Smart Storage
Parsed data is automatically stored in corresponding categories:

Nutrition Tracker

Calories, protein, fat, carbs, fiber, sugar

Daily/weekly/monthly summaries

Auto-fetch macros using USDA API or Nutritionix API

Exercise Log

Type, duration, sets, reps, resistance

Calories burned (estimated using MET values)

Vitals Log

Blood pressure, heart rate, weight, etc.

Date-stamped entries

Hydration

Water intake (in oz or cups)

Sleep Log

Hours slept, interruptions, sleep quality score (optional)

Mood/Stress (optional)

Sentiment analysis on speech to auto-track emotional tone

All data is stored in Firestore, Supabase, or a local DB depending on scale.

📊 3. Health Metrics Dashboard (Side Panel or Swipe View)
Organized into:

🍎 Nutrition: Daily totals + progress bars

🏋️ Exercise: History, load volume

💧 Water: Daily intake

😴 Sleep: Weekly trend

❤️ Vitals: Input log

📘 My Log: Raw transcript + AI interpretations

Each section is auto-populated from voice, no manual entry needed.
