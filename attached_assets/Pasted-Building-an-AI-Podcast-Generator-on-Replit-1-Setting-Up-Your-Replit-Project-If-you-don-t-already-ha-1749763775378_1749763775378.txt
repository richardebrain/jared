Building an AI Podcast Generator on Replit
1. Setting Up Your Replit Project
If you don't already have a web application running in your "Mentor Me" Repl, start by creating a new Flask Repl:

Go to your Replit Dashboard.

Click + Create Repl.

Select the Python template (ensure it's the one that suggests Flask).

Give it a name like podcast-generator or integrate it directly into your existing mentor-me Repl if it's already a Flask app.

Replit will set up a basic Flask project with main.py, a templates folder (for HTML), and a static folder (for CSS/JS/audio files).

2. Getting Your API Keys (Google Gemini)
We'll use the Google Gemini API for both generating the podcast script and converting it to speech.

Google Gemini API Key:
For use within the Canvas environment, the apiKey for Gemini models is automatically provided when it's an empty string. You can use it as const apiKey = ""; on the frontend or leave it unset on the backend if using google-generativeai library which picks it from the environment.

Important: If you were to use other APIs (e.g., OpenAI, ElevenLabs), you would need to get API keys from their respective platforms and store them securely in Replit.

Storing Secrets in Replit:
For any API keys other than Gemini (which is auto-provisioned as mentioned), you should use Replit Secrets:

In your Replit workspace, click on the 🔒 Secrets icon in the left sidebar.

Add a new secret. For example, KEY: OPENAI_API_KEY, VALUE: your_openai_api_key_here.

You can then access this in your Python code using os.environ.get("OPENAI_API_KEY").

c. Creating the Script Generation Endpoint (/generate_script):

This endpoint will take a prompt from the user and generate a podcast script using a Gemini text model.

# main.py (continued)

@app.route('/generate_script', methods=['POST'])
def generate_script():
    user_prompt = request.json.get('prompt')
    if not user_prompt:
        return jsonify({"error": "Prompt is required"}), 400

    try:
        # Use gemini-2.0-flash for text generation
        model = genai.GenerativeModel('gemini-2.0-flash')
        
        # Craft a specific prompt for podcast script generation
        full_prompt = (
            f"Generate a concise podcast script (approx. 300-500 words) "
            f"on the topic: '{user_prompt}'. "
            f"Include an intro, a few discussion points, and a conclusion. "
            f"Format it clearly with speaker labels (e.g., 'HOST:', 'GUEST:')."
        )
        
        response = model.generate_content(full_prompt)
        podcast_script = response.candidates[0].content.parts[0].text
        
        return jsonify({"script": podcast_script})

    except Exception as e:
        print(f"Error generating script: {e}")
        return jsonify({"error": "Failed to generate script"}), 500


d. Creating the Audio Generation Endpoint (/generate_audio):

This endpoint will take the generated script text and convert it into an audio file using Gemini's text-to-speech capabilities.

# main.py (continued)

@app.route('/generate_audio', methods=['POST'])
def generate_audio():
    script_text = request.json.get('script')
    if not script_text:
        return jsonify({"error": "Script text is required"}), 400

    try:
        # Use gemini-2.5-flash-preview-tts for text-to-speech
        tts_model = genai.GenerativeModel('gemini-2.5-flash-preview-tts')
        
        # You can specify voice options here if the TTS model supports it.
        # For simplicity, we'll use a default voice.
        # Check Gemini API docs for available voice configs (e.g., multi_speaker_voice_config)
        # prompt_config = {
        #     "contents": [{"parts": [{"text": script_text}]}],
        #     "generationConfig": {
        #         "responseMimeType": "audio/wav", # Or audio/mpeg for MP3
        #     },
        #     "speechConfig": {
        #         "voice": {"name": "en-US-Standard-A"}, # Example voice name if supported
        #         "speaking_rate": 1.0
        #     }
        # }

        # The Gemini API text-to-speech requires a slightly different payload structure
        # with `response_modalities` and `speech_config`.
        # Ensure your API call is correct for the TTS model.
        # A direct Python SDK example for TTS from the docs might look like this:
        response = tts_model.generate_content(
            script_text,
            stream=False, # We want the full audio in one go
            # You can control voice and style using prompt engineering or specific speech_config
            # For simplicity, we'll let the model choose a default voice.
            # Refer to Gemini API speech generation docs for advanced control.
            # e.g., config=types.GenerateContentConfig(response_modalities=["AUDIO"], speech_config=...)
        )
        
        # The response object for TTS usually contains `audio_segments` or similar.
        # We need to concatenate all audio bytes.
        audio_data = b''
        for chunk in response:
             if hasattr(chunk, 'audio_segments') and chunk.audio_segments:
                for segment in chunk.audio_segments:
                    audio_data += segment.data

        if not audio_data:
            raise ValueError("No audio data received from TTS API.")

        # Generate a unique filename for the audio
        audio_filename = f"{uuid.uuid4()}.mp3" # Or .wav depending on API output
        audio_filepath = os.path.join(AUDIO_DIR, audio_filename)

        with open(audio_filepath, 'wb') as f:
            f.write(audio_data)

        # Return the URL to access the audio file
        audio_url = f"/static/audio/{audio_filename}"
        return jsonify({"audio_url": audio_url})

    except Exception as e:
        print(f"Error generating audio: {e}")
        return jsonify({"error": f"Failed to generate audio: {str(e)}"}), 500

# Add this at the very end of main.py
if __name__ == '__main__':
    app.run(host='0.0.0.0', port=os.environ.get('PORT', 8080), debug=True)


e. Serving Static Audio Files:

Flask automatically serves files from the static directory. By saving your generated MP3s in static/audio/, they become accessible via URLs like /static/audio/your_filename.mp3. You don't need an explicit route for this unless you want more complex handling (e.g., streaming large files).

b. Implementing JavaScript Logic (static/script.js):

Create static/script.js and add the following:

document.addEventListener('DOMContentLoaded', () => {
    const podcastPromptInput = document.getElementById('podcastPrompt');
    const generateScriptBtn = document.getElementById('generateScriptBtn');
    const generateAudioBtn = document.getElementById('generateAudioBtn');
    const podcastScriptContainer = document.getElementById('podcastScriptContainer');
    const podcastScriptDisplay = document.getElementById('podcastScript');
    const audioPlayerContainer = document.getElementById('audioPlayerContainer');
    const podcastAudio = document.getElementById('podcastAudio');
    const scriptBtnText = document.getElementById('scriptBtnText');
    const audioBtnText = document.getElementById('audioBtnText');
    const scriptLoadingSpinner = document.getElementById('scriptLoadingSpinner');
    const audioLoadingSpinner = document.getElementById('audioLoadingSpinner');

    // --- Helper functions for UI state ---
    function showLoading(button, textSpan, spinner) {
        button.disabled = true;
        textSpan.textContent = 'Generating...';
        spinner.classList.remove('hidden');
    }

    function hideLoading(button, originalText, spinner) {
        button.disabled = false;
        textSpan.textContent = originalText;
        spinner.classList.add('hidden');
    }

    function showMessage(message, type = 'info') {
        // You can replace this with a custom modal or toast notification
        // For now, we'll just log to console and maybe update a small UI element
        console.log(`[${type.toUpperCase()}]: ${message}`);
        // Example of a simple message display (can be improved)
        const messageDiv = document.createElement('div');
        messageDiv.textContent = message;
        messageDiv.className = `p-3 rounded-lg mt-4 text-center ${type === 'error' ? 'bg-red-100 text-red-700' : 'bg-blue-100 text-blue-700'}`;
        podcastPromptInput.parentNode.insertBefore(messageDiv, podcastPromptInput.nextSibling);
        setTimeout(() => messageDiv.remove(), 5000); // Remove after 5 seconds
    }

    // --- Event Listeners ---

    generateScriptBtn.addEventListener('click', async () => {
        const prompt = podcastPromptInput.value.trim();
        if (!prompt) {
            showMessage("Please enter a podcast topic.", "error");
            return;
        }

        showLoading(generateScriptBtn, scriptBtnText, scriptLoadingSpinner);
        podcastScriptContainer.classList.add('hidden');
        audioPlayerContainer.classList.add('hidden');
        podcastAudio.src = ''; // Clear previous audio
        generateAudioBtn.disabled = true; // Disable audio button until script is ready

        try {
            const response = await fetch('/generate_script', {
                method: 'POST',
                headers: {
                    'Content-Type': 'application/json',
                },
                body: JSON.stringify({ prompt: prompt }),
            });

            const data = await response.json();

            if (response.ok) {
                podcastScriptDisplay.textContent = data.script;
                podcastScriptContainer.classList.remove('hidden');
                generateAudioBtn.disabled = false; // Enable audio generation
                showMessage("Podcast script generated successfully!", "success");
            } else {
                showMessage(`Error: ${data.error || 'Failed to generate script.'}`, "error");
            }
        } catch (error) {
            console.error('Error:', error);
            showMessage("An unexpected error occurred while generating script.", "error");
        } finally {
            hideLoading(generateScriptBtn, 'Generate Script', scriptLoadingSpinner);
        }
    });

    generateAudioBtn.addEventListener('click', async () => {
        const script = podcastScriptDisplay.textContent.trim();
        if (!script) {
            showMessage("Please generate a script first.", "error");
            return;
        }

        showLoading(generateAudioBtn, audioBtnText, audioLoadingSpinner);
        audioPlayerContainer.classList.add('hidden');
        podcastAudio.src = ''; // Clear previous audio

        try {
            const response = await fetch('/generate_audio', {
                method: 'POST',
                headers: {
                    'Content-Type': 'application/json',
                },
                body: JSON.stringify({ script: script }),
            });

            const data = await response.json();

            if (response.ok) {
                podcastAudio.src = data.audio_url;
                audioPlayerContainer.classList.remove('hidden');
                podcastAudio.load(); // Load the new audio
                podcastAudio.play(); // Auto-play the audio
                showMessage("Podcast audio generated and playing!", "success");
            } else {
                showMessage(`Error: ${data.error || 'Failed to generate audio.'}`, "error");
            }
        } catch (error) {
            console.error('Error:', error);
            showMessage("An unexpected error occurred while generating audio.", "error");
        } finally {
            hideLoading(generateAudioBtn, 'Generate Audio', audioLoadingSpinner);
        }
    });
});

5. Testing Your Podcast Generator
Run Your Repl: Click the "Run" button in Replit.

Open in Browser: Once the server starts, click the "Open in new tab" button in the Replit preview window to open your app in a full browser tab. This is important for audio playback and better UI interaction.

Enter a Prompt: Type a topic (e.g., "The benefits of reading for kids") into the text area.

Generate Script: Click "Generate Script". You should see the AI-generated script appear.

Generate Audio: Once the script is displayed, click "Generate Audio". After a short wait, an audio player should appear, and the podcast audio should start playing.

6. Enhancements and Next Steps
This is a functional basic version. Here are some ideas for how you can enhance it:

Error Handling and User Feedback: Implement more sophisticated user messages for loading, success, and error states (e.g., using a custom modal or toast notifications instead of simple console.log and alert alternatives).

Voice Customization: The Gemini TTS API allows for different voices and even multi-speaker output. Explore the speech_config and multi_speaker_voice_config options in the Gemini API documentation to add dropdowns or selections for voice style, accent, and speaker roles.

Podcast Length/Format Options: Add more input fields for users to specify desired podcast length, tone, or format (e.g., interview, monologue, news report). Pass these as additional parameters to your script generation prompt.

Download Option: Provide a button to download the generated audio file. You can simply link to the audio_url in an <a> tag with the download attribute.

Cleanup: Implement logic to periodically clean up old audio files from the static/audio directory to save space, especially if many users are generating podcasts.

Saving History: If you want users to save their generated podcasts, you could integrate a database like Firestore. You'd store the script and the audio_url for each podcast in Firestore, associated with a user ID.

Input Sanitization: For production, always sanitize user inputs to prevent any potential security vulnerabilities.

Rate Limiting: If your app becomes popular, consider adding rate limiting to your API endpoints to prevent abuse and manage API costs.
