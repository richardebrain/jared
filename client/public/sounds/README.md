# Sound Credits

These sound effect files are placeholders for Mario-themed sound effects. For legal use in a production environment, you would need to obtain properly licensed sound files.

Sound names and their purposes:
- mario-coin.mp3: Success sound for correct answers
- mario-wrong.mp3: Error sound for incorrect answers
- mario-level-complete.mp3: Sound when a level is completed
- mario-victory.mp3: Celebratory sound for significant achievements

In this training app, these sounds add a gamification element that makes learning more engaging and rewarding for teachers.
