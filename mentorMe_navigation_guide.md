# MentorMe ECE Platform - Complete Navigation Guide

## Main Navigation (Available from Header)

### 📊 Dashboard
- **Location**: Click "Dashboard" in header or go to `/dashboard`
- **Purpose**: Your home base showing progress, streaks, points, modules, and announcements
- **Features**: 
  - View your points (Bear Bucks) and current streak
  - See recommended modules for your growth
  - Check recent shout-outs and newsletters
  - Access bonus boxes and rewards

### 📚 Modules
- **Location**: Click "Modules" in header or go to `/modules`
- **Purpose**: Browse and take training modules for professional development
- **Features**:
  - Browse all available modules
  - Filter by category (trauma-informed care, classroom management, etc.)
  - View community modules created by other teachers
  - Track your progress and earn ECE hours
  - Rate and comment on modules

### 📝 Assessment
- **Location**: Click "Assessment" in header or go to `/assessment`
- **Purpose**: Take adaptive assessments to evaluate your knowledge
- **Features**:
  - Adaptive difficulty that adjusts to your performance
  - Earn points for correct answers (5-20 points based on difficulty)
  - Get personalized learning recommendations
  - Track your assessment history

### 🛠️ Tools
- **Location**: Click "Tools" in header or go to `/tools`
- **Purpose**: Access professional teaching tools and AI assistants
- **Available Tools**:
  - **Parent Response Generator**: Craft professional communications for difficult parent conversations
  - **Lesson Plan Tools**: Create basic or advanced lesson plans with Arizona standards
  - **Personalized Stories**: Create custom behavioral stories with children's names and voice narration
  - **Transition Timer**: Help children transition smoothly between activities
  - **Suessify Generator**: Transform text into Dr. Seuss-style rhymes
  - **Video Library**: Access educational videos for professional growth
  - **Help Me With This Kid**: Expert strategies for challenging behaviors
  - **Child Portfolio Builder**: AI-powered photo analysis and portfolio creation
  - **Director Meeting Scheduler**: Book time with your school director
  - **Classroom Music Studio**: Access 19 classroom songs organized by category

## Special Feature Pages

### 🎵 Classroom Music Studio
- **Location**: `/classroom-music` or through Tools page
- **Purpose**: Access your complete music collection for classroom management
- **Features**:
  - 19 songs organized by category (cleanup, transitions, meals, rest, sharing, welcome, core values)
  - Search and filter by category
  - Play/pause controls with progress tracking
  - Favorites system
  - Volume control and mute options

### 📷 Portfolio Builder
- **Location**: `/portfolio-builder` or through Tools page
- **Purpose**: Create and manage child portfolios with AI assistance
- **Features**:
  - Upload photos with AI analysis
  - Voice input for context and observations
  - Automatic child assignment based on facial recognition
  - Developmental milestone tracking
  - Individual child profile navigation
  - NAEYC and Head Start compliant documentation

### 🎯 Core Values
- **Location**: `/core-values`
- **Purpose**: Engage with your school's core values
- **Features**:
  - View and interact with school-specific core values
  - Submit core values shout-outs for colleagues
  - See community recognition and achievements

### 🧘 Mindful Mornings
- **Location**: `/mindful-mornings`
- **Purpose**: Start your day with mindfulness practices
- **Features**:
  - Guided mindfulness exercises
  - Daily reflection prompts
  - Stress reduction techniques for educators

### 🎮 Games
- **Location**: `/games`
- **Purpose**: Educational games for skill development
- **Features**:
  - Various educational mini-games

  - Skill-building through play

### 🤖 Beary AI
- **Location**: Click Beary AI chat button (bottom right)

## Navigation Tips

### How to Get Anywhere:
1. **From Dashboard**: Use the main navigation in the header to access any major section
2. **Quick Access**: Use the Tools page as a hub for most professional tools
3. **Beary AI**: Click the chat button anytime for navigation help
4. **Breadcrumbs**: Most pages have "Back to Dashboard" buttons for easy return

### Common Workflows:
- **Taking Training**: Dashboard → Modules → Select Module → Complete Sections → Earn Points/ECE Hours
- **Creating Lesson Plans**: Tools → Lesson Plan Tools → Choose Basic or Advanced
- **Managing Portfolios**: Tools → Portfolio Builder → Upload Photos → Add Voice Notes → AI Analysis
- **Professional Development**: Dashboard → Assessment → Complete Questions → Get Recommendations
- **Classroom Management**: Tools → Classroom Music Studio → Select Songs for Activities

### Point System:
- **Assessments**: 5-20 points based on difficulty
- **Modules**: Points vary by module complexity
- **Games**: Points for completion and achievements
- **Bonus Boxes**: Special rewards for daily login streaks

### Getting Help:
- **Beary AI**: Instant chat assistance for navigation and feature questions
- **Director Meeting Scheduler**: Book time with school administrators
- **Video Library**: Educational resources for additional support

This guide covers all major navigation paths and features in the MentorMe platform. Users can access most features through the main header navigation, with specialized tools available through the Tools page hub.
