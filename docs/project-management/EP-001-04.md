## Task Description
Add proper database indexes to support efficient weighted question selection and assessment queries. Optimize database performance for the adaptive assessment system with focus on question selection bottlenecks.

## Requirements

### Core Index Requirements
- **Domain and Difficulty Lookups**: Optimize queries for 1-6 difficulty levels across domains
- **User Assessment Queries**: Optimize user-specific assessment retrieval and progress tracking
- **Weighted Question Selection**: Performance optimization for complex selection algorithm
- **Availability Checking**: Efficient platform and school-level availability queries

### Specific Index Targets

#### assessmentDomains Indexes
- **Active Status Index**: Fast filtering of active domains
- **Display Order Index**: Efficient ordering for UI display
- **Name Lookup Index**: Quick domain name searches

#### assessmentQuestions Indexes
- **Critical Composite Index**: domain+difficulty+availability for weighted selection
- **Approval Status Index**: Quick filtering of approved questions
- **Domain-specific Index**: Fast domain-based queries
- **Difficulty Level Index**: Efficient difficulty-based filtering

#### assessmentResponses Indexes
- **User Analytics Index**: User+assessment+domain composite for progress tracking
- **Sequence Tracking Index**: Question sequence and timing analysis
- **Performance Analytics Index**: Response timing and accuracy analysis

#### questionAvailability Indexes
- **School-Level Index**: Efficient school-specific availability checking
- **Question-Level Index**: Fast question availability lookups
- **Composite School+Question Index**: Optimal availability validation

#### assessmentConfig Indexes
- **School Configuration Index**: School-specific configuration lookups
- **Platform Configuration Index**: Global configuration retrieval

#### assessments Indexes
- **User Assessment Index**: User-specific assessment queries
- **Completion Status Index**: Assessment completion tracking
- **Temporal Analytics Index**: Time-based assessment analysis

## Technical Implementation

### Index Definitions (Drizzle Schema)
```typescript
// assessmentDomains indexes
index('idx_assessment_domains_active').on(assessmentDomains.isActive),
index('idx_assessment_domains_display_order').on(assessmentDomains.displayOrder),
index('idx_assessment_domains_name').on(assessmentDomains.name),

// assessmentQuestions indexes (CRITICAL)
index('idx_assessment_questions_domain_difficulty_availability')
  .on(assessmentQuestions.domainId, assessmentQuestions.difficulty, assessmentQuestions.isEnabled),
index('idx_assessment_questions_approval').on(assessmentQuestions.isApproved),
index('idx_assessment_questions_domain').on(assessmentQuestions.domainId),

// assessmentResponses indexes
index('idx_assessment_responses_user_assessment_domain')
  .on(assessmentResponses.userId, assessmentResponses.assessmentId, assessmentResponses.questionId),
index('idx_assessment_responses_sequence').on(assessmentResponses.questionSequence),
index('idx_assessment_responses_timing').on(assessmentResponses.responseTime, assessmentResponses.timeSpent),

// questionAvailability indexes
index('idx_question_availability_school').on(questionAvailability.schoolId),
index('idx_question_availability_question').on(questionAvailability.questionId),
index('idx_question_availability_composite')
  .on(questionAvailability.schoolId, questionAvailability.questionId),

// assessmentConfig indexes
index('idx_assessment_config_school').on(assessmentConfig.schoolId),
index('idx_assessment_config_platform').on(assessmentConfig.schoolId), // NULL for platform

// assessments indexes
index('idx_assessments_user').on(assessments.userId),
index('idx_assessments_completion').on(assessments.completedAt),
index('idx_assessments_temporal').on(assessments.createdAt, assessments.completedAt)
```

### Performance Impact Analysis
- **🚀 Weighted Question Selection**: Composite domain+difficulty+availability index eliminates table scans
- **🚀 User Analytics**: User+assessment+domain composite enables fast progress tracking
- **🚀 Availability Checking**: School-level indexes optimize permission-based question filtering
- **🚀 Assessment Completion**: Temporal indexes support dashboard analytics and reporting
