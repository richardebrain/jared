# EP-001-05: Seed Assessment Domains and Configuration

**Epic:** EP-001 - Implement Dynamic Initial Assessment for Educators  
**Status:** ✅ Completed  
**Dependencies:** EP-001-03  
**Assignee:** Data Management  
**Estimated Effort:** 1 day  

## Task Description
Create seed data for the 10 ECE domains with proper weights and default configuration values. Establish the foundation data structure for the adaptive assessment system.

## Requirements

### Core Seed Data Requirements
- **10 ECE Domains**: Accurate domain names, descriptions, and relative weights
- **Domain Weight System**: Proportional allocation supporting 40-question assessments
- **Default Configuration**: Standard assessment settings (40 questions, 60 seconds per question)
- **Platform-wide Settings**: Universal default configuration for all schools

### Detailed Domain Specifications

#### Required ECE Domains
1. **Child Safety & Supervision** (weight: 10)
   - High priority domain for educator competency
   - Covers physical safety, supervision strategies, risk assessment
   
2. **Health & Development** (weight: 8)
   - Child health monitoring, developmental milestones, health practices
   
3. **Trauma-Informed & Emotional Care** (weight: 7)
   - Social-emotional development, trauma-informed practices, mental health
   
4. **Positive Guidance** (weight: 8)
   - Behavior guidance, positive discipline, classroom management
   
5. **Curriculum & Learning Through Play** (weight: 8)
   - Age-appropriate curriculum, play-based learning, educational activities
   
6. **Family Engagement** (weight: 5)
   - Parent communication, family partnerships, cultural responsiveness
   
7. **Assessment & Observation** (weight: 5)
   - Child assessment, observation techniques, progress documentation
   
8. **Professionalism & Ethics** (weight: 4)
   - Professional standards, ethical practices, continuing education
   
9. **Cultural & Individual Inclusion** (weight: 4)
   - Diversity, inclusion practices, individualized care
   
10. **Real Classroom Scenarios** (weight: 6)
    - Practical application, real-world situations, problem-solving

### Configuration Requirements

#### Default Assessment Configuration
- **Total Questions**: 40 questions per assessment
- **Time Per Question**: 60 seconds (1 minute) default
- **Starting Difficulty**: Level 3 (Medium) for balanced initial assessment
- **Platform Scope**: School ID null for universal default settings

#### Weight System Logic
- **Total Domain Weights**: 65 (allows proportional selection)
- **Relative Distribution**: Weights determine question allocation probability
- **Flexible Allocation**: System selects questions proportionally, not exactly
