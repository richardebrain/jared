# EP-001-03: Update Database Schema with Assessment Tables

**Epic:** EP-001 - Implement Dynamic Initial Assessment for Educators  
**Status:** ✅ Completed  
**Dependencies:** EP-001-02  
**Assignee:** Database Development  
**Estimated Effort:** 2 days  

## Task Description
Implement new database schema for assessment system using Drizzle's codebase-first approach with `drizzle-kit push`. Update existing schema to support the 6-level adaptive assessment system with weighted domain distribution.

## Requirements

### Core Database Schema Updates
- **Add `assessmentDomains` table**: Question weights for 10 ECE domains with descriptions and display order
- **Update `assessmentQuestions` table**: Add domainId reference and 6 difficulty levels support
- **Update `assessmentResponses` table**: Add questionSequence field for complete tracking
- **Add `questionAvailability` table**: Dual-level availability control (platform and school)
- **Update `assessmentConfig` table**: 40 question default and 60-second timePerQuestion
- **Update `assessments` table**: New fields for 6-level adaptive system

### Technical Approach
- **Codebase-First Strategy**: Update TypeScript schema in `shared/schema.ts` as source of truth
- **Direct Database Push**: Use `drizzle-kit push` to apply schema changes directly
- **No SQL Migration Files**: Let Drizzle handle the diff automatically
- **Type Safety**: Ensure proper TypeScript types for all new fields

### Detailed Schema Requirements

#### assessmentDomains Table
```sql
CREATE TABLE assessmentDomains (
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL,
  description TEXT,
  weight INTEGER NOT NULL,
  displayOrder INTEGER,
  isActive BOOLEAN DEFAULT true,
  createdAt DATETIME DEFAULT CURRENT_TIMESTAMP,
  updatedAt DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

#### assessmentQuestions Table Updates
```sql
ALTER TABLE assessmentQuestions ADD COLUMN domainId INTEGER REFERENCES assessmentDomains(id);
-- Difficulty levels 1-6 (Easy to Master)
-- Update existing difficulty field to support 1-6 range
```

#### assessmentResponses Table Updates
```sql
ALTER TABLE assessmentResponses ADD COLUMN questionSequence INTEGER;
-- Track order of questions in assessment
```

#### questionAvailability Table
```sql
CREATE TABLE questionAvailability (
  id INTEGER PRIMARY KEY,
  questionId TEXT NOT NULL REFERENCES assessmentQuestions(id),
  schoolId INTEGER REFERENCES schools(id),
  isEnabled BOOLEAN DEFAULT true,
  createdAt DATETIME DEFAULT CURRENT_TIMESTAMP,
  updatedAt DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

#### assessmentConfig Table Updates
```sql
-- Update to support new assessment structure
ALTER TABLE assessmentConfig ADD COLUMN totalQuestions INTEGER DEFAULT 40;
ALTER TABLE assessmentConfig ADD COLUMN timePerQuestion INTEGER DEFAULT 60;
ALTER TABLE assessmentConfig ADD COLUMN startingDifficulty INTEGER DEFAULT 3;
```

#### assessments Table Updates
```sql
-- Add fields for 6-level adaptive system
ALTER TABLE assessments ADD COLUMN currentDifficulty INTEGER DEFAULT 3;
ALTER TABLE assessments ADD COLUMN difficultyProgression TEXT; -- JSON array
ALTER TABLE assessments ADD COLUMN domainCoverage TEXT; -- JSON object
```
