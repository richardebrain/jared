## Task Description
Create comprehensive frontend components for the assessment experience including question display, timer management, answer submission, and progress tracking throughout the 40-question adaptive assessment journey.

## Requirements

### Core Assessment Interface Requirements
- **Question Display Component**: Clean, professional presentation of assessment questions
- **Timer Integration**: Frontend timer with backend synchronization and automatic progression
- **Answer Selection Interface**: Multiple choice answer selection with validation
- **Progress Tracking**: Visual progress indicator showing assessment completion status
- **Domain Information**: Display current question domain and difficulty level

### Advanced Assessment Features
- **Server-Authoritative Timing**: Backend-controlled timer with frontend synchronization
- **Automatic Progression**: Questions advance automatically on timeout
- **Real-time Validation**: Immediate answer validation and submission
- **Professional UI Design**: ECE educator-focused interface design
- **Responsive Layout**: Optimized for desktop and mobile assessment taking
